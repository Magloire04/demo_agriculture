# AgriFon 100 % fon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** No French on the farmer's screens: all text in Fon from one reviewed source, Fon-only solutions illustrated with numbered SVG steps, and a temporary review page where Elisée corrects and validates every Fon text.

**Architecture:** UI texts live in `data/interface.json`; a generator writes `site/js/textes.js` and fills `data-texte` elements of the static pages, so nothing French ever paints. Review rows are exported from the data files to a private claude.ai artifact with a database; Elisée validates there; validated rows are applied back with a tested script. Solutions carry an `illustration` id pointing to one SVG per series under `site/img/conseils/`.

**Tech Stack:** Node ≥20.12, ES modules, no npm dependencies, `node --test`; vanilla JS PWA in `site/`; Artifact tool (claude.ai page with `db` capability) for the review page.

**Spec:** `docs/superpowers/specs/2026-11-02-agrifon-100-fon-design.md`

## Global Constraints

- Farmer screens (`site/index.html`, `site/hors-service.html`, `site/manifest.webmanifest`, everything `site/js/app.js` displays) show no French. Allowed literal tokens: `AgriFon`, `F CFA`, `F`, `kg`, `L`, `m²`, `h`, `PAM`, `CC BY-IGO`, `JaimeMaLangue`, `Access Agriculture`, `JML`, `OmniVoice`, `FongLab`, `CC BY-NC 4.0`, market/commune/department names, variety names, digits.
- `/conseiller`, `/admin`, API JSON fields, simulation banners stay French.
- Never show the server's French `message` to the farmer; missing Fon → generic Fon « réessayez » (`erreur_reessayer`).
- Dates and numbers in digits: `MM/AAAA`, `HH:MM`, `1 500`.
- Images: flat colours, numbered steps (white digit in a `#006828` disc, top-left), three panels per row at 336 px, no words except digits and units; only quantities present in the reviewed Fon; no dose for Spinosad (`tomate-helicoverpa`) and neem kernel extract (`coton-pucerons`); no PPE drawn, no hand touching a product.
- Fon is NFC everywhere; `{marques}` (`{produit}`, `{prix}`…) are preserved by any correction.
- Commits: English Conventional Commits, no AI trace. Elisée merges PRs. PR 1 = Tasks 1–9; PR 2 = Tasks 10–14.

## Review Focus

1. A French string reaching the farmer through an error path (`erreurDans`, `appelerApi` network errors, GPS errors) → every path shows Fon; pinned by Task 6's guard test and Task 8's browser sweep.
2. A correction that drops a `{marque}` → refused with an alert, data unchanged (Task 2 test).
3. A corrected `fon` whose spoken `voix` was not corrected → alert naming the row (Task 2 test).
4. Review input typed with combining tone marks (NFD) → stored NFC (Task 2 test).
5. An `illustration` id with no SVG file, or an SVG containing words → refused (Task 10 test).
